# Forge UI C 端客户端 PRD

## 1. 产品定位

Forge UI 是一个面向个人开发者、业务分析师和内部工具使用者的桌面客户端。它连接已经存在的 OpenAPI/Swagger 后台服务，让用户通过自然语言生成可运行的业务界面，而不必为每个后台重复编写固定前端页面。

核心承诺：**连接一次，描述需求，得到可复用的业务工作台。**

产品不是低代码编辑器，也不是让模型生成任意代码的网页构建器。它使用受控的 `PageSpec` UI DSL 渲染查询、Dashboard、表格、详情、表单和 CRUD，所有写操作必须由用户明确提交。

## 2. 目标用户与场景

- 需要快速查看内部系统数据的个人开发者和技术负责人。
- 维护多个后台服务、但不想为每个服务写固定前端的业务人员。
- 需要临时生成报表、资源管理页和运营总览的团队成员。

典型任务：连接一个已有 API；让 Forge 生成“本周订单总览”；继续对话增加筛选、指标或编辑入口；满意后保存为模板，下次直接复用。

## 3. 信息架构

1. **总览**：最近使用、已保存模板、连接状态和快捷开始。
2. **生成工作台**：对话输入、模型选择、生成结果预览、继续修改和保存模板。
3. **模板库**：搜索、分类、收藏/固定、版本历史、导入导出和打开模板。
4. **业务连接**：OpenAPI 导入、鉴权、operation 授权和连接测试。
5. **模型服务**：AI 模型配置、切换、测试和安全状态。

导航应优先呈现前 3 个 C 端高频入口，连接与模型放在“设置”语义下，避免用户一进入产品就面对技术配置。

## 4. 核心体验

### 4.1 首次使用

总览页用一个明确的主 CTA 引导用户“连接后台服务”或“开始描述需求”。未配置连接时显示轻量设置引导，不阻断用户浏览模板和体验生成式 UI。

### 4.2 对话生成

用户输入自然语言，选择当前业务连接和模型，点击生成或使用快捷键提交。客户端请求模型生成合法 `PageSpec`，渲染成页面预览，并展示所使用的 operation、数据状态和安全边界。

用户可以继续输入“增加一个状态筛选”“把列表改成按地区分组”等指令。每次修改均产生新版本，失败时保留当前可用页面。

### 4.3 模板复用

生成结果可以保存为模板。模板保存的是页面结构、operation 绑定和展示偏好，不包含 API Key、Token、企业 CA 私钥和真实业务数据。模板库支持打开、重命名、固定到总览、查看版本、恢复、导入、导出和删除。

### 4.4 业务操作

查询和统计可以自动加载；新增、编辑、删除必须通过页面内表单、提交按钮和二次确认完成。未授权 operation、非法目标地址和无效 DSL 均在 Rust 层拒绝。

## 5. 视觉与交互方向

参考 `VoltAgent/awesome-design-md` 中 Linear、Raycast、OpenCode、Supabase 的共同优点，采用“暗色工作台 + 精准网格 + 单一高亮色”的桌面产品语言：深炭黑背景、酸性黄绿色作为行动信号、等宽小标签表达状态，界面保持数据密度但不牺牲留白。

设计关键词：安静、锋利、可信、可探索。避免营销型大渐变、过度圆角、紫色 AI 光效和把所有功能塞进一页。动效只用于页面进入、状态切换、生成中反馈和可点击卡片的微交互。

## 6. 技术与组件边界

- React 页面只负责视图编排和交互状态；网络、凭证、TLS、OpenAPI 解析和业务请求由 Rust/Tauri 完成。
- 路由、页面、数据 hooks、展示组件和操作组件分离；单个页面组件不承载所有持久化逻辑。
- `PageSpec` 是唯一可执行 UI 描述，所有模型输出通过版本化 Schema 校验。
- 模板、会话和模型配置通过独立 hooks/repository 访问；组件通过 props 接收回调。
- 关键交互组件与 hooks：`PromptBox`、`TemplatePicker`、`GeneratedWorkbenchView`、`TemplateRoute`、`useWorkbenchModelActions`、`parsePageSpec`、`isModelConfigured`、`ConnectionStatus`、`EmptyState`、`StatCard`。

## 7. MVP 验收标准

- 用户从总览页可在 1 次点击内进入生成工作台或模板库。
- 用户能看到最近生成记录、已保存模板和业务连接状态。
- 应用重启后能恢复已保存的 OpenAPI 摘要和业务连接元数据，不要求用户重复导入规范；凭证仍只从系统钥匙串读取。
- 总览明确显示 AI 模型、业务 API 和模板库的就绪状态；未就绪项提供直达设置入口。
- 所有按钮、输入框和选择器使用统一的控制高度、圆角、字号、间距和键盘 focus 状态；窄屏下导航、卡片、模板工具栏和表单不发生横向溢出。
- 生成工作台支持自然语言生成、继续修改、打开历史和保存模板。
- 生成工作台可以选择一个已保存模板作为结构上下文；发送给模型前只保留安全结构，不包含真实 rows/stats 或密钥。
- 模板库支持打开、搜索、固定、重命名、版本查看、恢复、导入、导出和删除。
- 查询、统计、详情、增删改查和导出能力保持可用，写操作仍需用户主动提交。
- 页面不向模型发送真实业务 rows/stats，模板导出不包含任何密钥。
- `npm run build`、Rust 测试和现有安全校验通过。

## 8. 后续迭代

- 模板标签、收藏、最近使用排序和跨连接重新绑定向导。
- Dashboard 小组件拖拽编排与多页面工作区。
- 对话线程、生成差异预览和可撤销的页面变更。
- 更完整的无障碍、键盘导航、跨平台安装和真实 mock server E2E 测试。
